# Customer Data Export Contract

SBB Dashboard is the independent source system. Add Settings > Download Data, owner-only, with individual CSV files and a ZIP containing manifest.json and CSV datasets: categories, menu items, modifiers, recipes, recipe ingredients, ingredients, supplier purchasing, expenses, stock, sales and transactions. Include source IDs and cross-reference keys, units, currencies, timestamps and cost precision. Never silently omit records. ZIP manifest reports counts, schema versions, exported timestamp and checksums. Images should be packaged when licensed and available. Export should be read-only, streamed for large accounts, and audited. Do not call V3 APIs or depend on V3 schema; use documented portable headings. Test CSV escaping, formula injection, role enforcement, empty datasets and round-trip referential integrity.
